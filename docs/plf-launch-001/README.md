# PLF Launch 001 — The False Opportunity Problem

This folder contains the publication-safe Product Launch Formula assets for RESONANCE Verify.

## Core thesis

> Visible edge is not executable edge.

RESONANCE Verify sits between a proposed trade and the existing executor:

```text
strategy / agent signal
→ RESONANCE Verify
→ ALLOW / OBSERVE / REJECT
→ existing execution system
```

The launch is a market-learning campaign. It does not sell signals, promise returns, place orders, request credentials, control wallets, or use live capital.

## Evidence anchor

The first measurement-corrected Campaign 002 sample contains 20 terminal public-market triangular cycles:

```text
20 complete evidence
19 structural-pass
2 gross-positive before costs
0 net-positive after modeled costs
0 EXECUTE_SIM
```

Mean modeled cost drag: 35.94 bps. Maximum gross edge: 1.65 bps.

This is an early funnel observation, not an Opportunity Truth Rate and not a profitability result. OTR is unavailable because no candidate crossed `EXECUTE_SIM`.
