# v0.3 — Opportunity Memory & Truth Metrics

v0.3 adds an append-only causal memory for paper-only arbitrage outcomes.

## Causal loop

```text
market snapshot
  -> candidate opportunity
  -> quote-bound evidence
  -> expected edge
  -> paper outcome
  -> prediction error
  -> truth classification
  -> observation journal
  -> reliability metrics
```

The goal is not to maximize raw detected spread. The goal is to measure which signals survive the modeled execution path often enough to deserve higher confidence later.

## Identity

`logical_operation_id` identifies one semantic opportunity across retries. `execution_id` identifies one concrete observation attempt.

```text
logical operation OP-42
  attempt 1 / execution A -> INDETERMINATE
  attempt 2 / execution B -> TRUE_POSITIVE
```

Truth metrics collapse those rows into one logical operation. A retry is not a second opportunity.

The journal enforces sequential attempts, stable `opportunity_id`, stable `route_id`, stable detection time, globally unique execution IDs, and no new attempt after a terminal outcome.

## Evidence binding

`observation_from_evidence(...)` accepts an existing deterministic `EvidenceReceipt`. Before an observation can be created it:

1. Recomputes SHA-256 over the receipt canonical JSON.
2. Rejects a malformed or mismatched digest.
3. Takes `logical_operation_id` directly from the receipt rather than accepting a second caller-supplied copy.
4. Derives expected net edge and expected verdict from the receipt.
5. Derives realized paper edge from the receipt when an observed paper outcome exists.
6. Derives the truth class from those inputs.

This prevents a journal row from claiming provenance that is not present in the supplied receipt.

## Outcome classes

- `TRUE_POSITIVE`: an `EXECUTE_SIM` signal has an observed paper edge at or above the required edge threshold.
- `FALSE_POSITIVE`: an `EXECUTE_SIM` signal has an observed paper edge below the required edge threshold.
- `EXPIRED`: the opportunity expired before a terminal paper outcome could be observed.
- `REJECTED`: the verifier rejected the candidate.
- `INDETERMINATE`: no terminal truth label is justified yet, including retries/timeouts or `OBSERVE` candidates.

`REJECTED` and `INDETERMINATE` are not false positives.

## Metrics

Opportunity Truth Rate:

```text
TRUE_POSITIVE / (TRUE_POSITIVE + FALSE_POSITIVE)
```

False Opportunity Rate:

```text
FALSE_POSITIVE / (TRUE_POSITIVE + FALSE_POSITIVE)
```

Route Survival Rate:

```text
(TRUE_POSITIVE + FALSE_POSITIVE)
/
(TRUE_POSITIVE + FALSE_POSITIVE + EXPIRED)
```

Mean prediction error is calculated over truth-bearing paper outcomes only:

```text
observed_edge_bps - expected_edge_bps
```

## Journal boundary

The v0.3 journal is deterministic JSONL and explicitly single-writer. Every successful append is flushed and fsynced. Multi-process locking and an external database are intentionally out of scope; a future storage layer must preserve the same logical-operation and terminal-state invariants.

## Safety boundary

v0.3 remains paper-only. It adds no private exchange API, account access, signing, wallet interaction, order placement, cancellation, transfer, bridge, or live execution path.
