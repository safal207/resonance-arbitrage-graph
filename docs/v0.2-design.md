# v0.2 causal design

```text
public quote
  -> normalized QuoteSnapshot
  -> explicit fee/slippage assumptions
  -> graph trade edges
  -> bounded cycle discovery
  -> causal verifier
  -> paper verdict
  -> quote-bound evidence
```

## Why single-venue triangular execution first

A cross-venue price gap is not an executable cycle by itself. Capital and inventory end in different venue states unless rebalance/settlement transitions are modeled. v0.2 therefore permits cross-venue observations but labels them `OBSERVE_ONLY_REBALANCE_UNMODELED`.

A later version may introduce explicit transfer/rebalance edges with fees, latency, capacity, withdrawal/deposit state, and settlement probability. Until then there is no cross-venue `EXECUTE_SIM` path.

## Fee model

Fees and slippage are mandatory caller-supplied assumptions. The engine does not infer a user's exchange fee tier and does not treat a public quote as net executable without costs.
