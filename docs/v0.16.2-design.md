# v0.16.2 — Real Market Replay Corpus

## Purpose

The predictive layer now has a real ML candidate, but model quality is meaningless until it is evaluated on observations that were actually unknown at decision time. v0.16.2 adds the missing data boundary: a hash-chained, public-market, paper-only replay corpus that can be exported directly into the existing `ReplayBundle` contract.

## Causal sequence

```text
public market quotes + rolling windows
        ↓
cycle scan at decision time
        ↓
DECISION record (ReplayCase attempt 1, nonterminal)
        ↓
later public quote observation
        ↓
OUTCOME record (same decision fingerprint, next attempt)
        ↓
verifier recomputes future route edge from stored outcome quotes
        ↓
canonical ReplayBundle export
        ↓
HistoricalMean vs CatBoost walk-forward
```

## Append-only semantics

A decision is never edited when the future becomes known.

- `DECISION` stores replay attempt 1 with the exact decision-time snapshots, rolling windows, route legs, costs and policies.
- `OUTCOME` stores the next replay attempt for the same `logical_operation_id` and decision fingerprint.
- records form a SHA-256 chain through `previous_record_sha256`;
- the corpus envelope has its own canonical SHA-256;
- existing `ReplayBundle` validation independently enforces contiguous attempts and rejects decision drift across retries.

The JSON file may be atomically rewritten as a storage implementation detail, but valid history is append-only at the record-contract layer: changing an earlier record breaks every downstream hash binding.

## Outcome evidence

A terminal future-edge label cannot be supplied as an unsupported scalar. The `OUTCOME` record carries the fresh public `QuoteSnapshot` values used for resolution. Verification reconstructs the exact original semantic route, re-applies the original per-leg cost assumptions, runs the existing route evaluator, and requires the stored `realized_net_edge_bps` to match the recomputed result.

If an exact future quote for any original route market is missing or ambiguous, resolution fails closed.

## Meaning of realized edge

`realized_net_edge_bps` in this corpus means:

> the paper-model net edge of the same semantic route when repriced against the later stored public top-of-book snapshot.

It is **not** evidence of an exchange fill, executable latency, queue position, account-tier fee, wallet transfer, or realized live trading profit. It is the future public-market target used by the research benchmark.

## Safety boundary

The corpus uses public market-data adapters only.

It does not add or require:

- exchange credentials;
- private account endpoints;
- order placement;
- wallet signing;
- stablecoin transfers;
- live capital allocation;
- automatic model/policy promotion.

## CLI

Capture decision-time candidates:

```bash
resonance-real-market-corpus capture \
  --corpus data/binance-corpus.json \
  --venue binance \
  --pair BTCUSDT:BTC:USDT \
  --pair ETHBTC:ETH:BTC \
  --pair ETHUSDT:ETH:USDT \
  --start-asset USDT \
  --amount 1000 \
  --fee-bps 10 \
  --slippage-bps 5
```

Later, append fresh public outcomes:

```bash
resonance-real-market-corpus resolve \
  --corpus data/binance-corpus.json \
  --venue binance \
  --pair BTCUSDT:BTC:USDT \
  --pair ETHBTC:ETH:BTC \
  --pair ETHUSDT:ETH:USDT
```

Verify the complete causal/evidence chain:

```bash
resonance-real-market-corpus verify --corpus data/binance-corpus.json
```

Export into the existing replay contract:

```bash
resonance-real-market-corpus export \
  --corpus data/binance-corpus.json \
  --output data/binance-replay-bundle.json
```

The exported bundle can then be consumed by the existing replay/predictive tooling, including the CatBoost walk-forward benchmark.

## Next research gate

Do not add PyTorch, sequence models or RL merely because the adapter exists. First accumulate a nontrivial public corpus and compare CatBoost against `HistoricalMeanBaseline` on untouched chronological outcomes. Model complexity only earns promotion when it adds reproducible out-of-sample economic signal under the same paper-only safety boundary.
