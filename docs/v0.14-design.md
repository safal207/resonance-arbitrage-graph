# v0.14 — Policy Lineage Registry

v0.14 adds deterministic release identity, append-only lineage, supersession, revocation, and registry verification for promoted paper policies.

The event chain is hash-linked. One release may be ACTIVE; predecessors become SUPERSEDED; revocation is terminal for the lineage.

Structural verification checks registry history and receipt bindings. Full verification replays the v0.13 upstream evidence chain before accepting each release.

This layer is offline and paper-only. ACTIVE is a registry state, not live-execution authorization.
