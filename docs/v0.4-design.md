# v0.4 — Reliability-Adjusted Ranking

v0.4 turns v0.3 outcome memory into a conservative ranking signal for new paper-only opportunities.

## Causal loop

```text
current market candidate
  -> verifier verdict + raw expected edge
  -> matching historical logical operations
  -> Bayesian truth estimate
  -> survival estimate
  -> historical prediction-bias penalty
  -> sample-confidence guard
  -> reliability-adjusted paper ranking
```

The ranking layer does not replace the verifier. A candidate that is not already `EXECUTE_SIM` is ineligible for reliability ranking.

## Reliability profile

History is first collapsed by `logical_operation_id`, preserving the v0.3 retry semantics. A profile is then segmented by:

- exact `route_id`
- caller-selected market-context keys (default: `venue`, `regime`)

Unrelated routes and contexts cannot contribute to a profile.

The profile tracks:

- truth samples (`TRUE_POSITIVE + FALSE_POSITIVE`)
- expiries
- Bayesian-smoothed Opportunity Truth Rate
- Bayesian-smoothed Route Survival Rate
- mean prediction error over truth-bearing outcomes
- history confidence based on sample size

## Bayesian shrinkage

Tiny samples must not produce extreme confidence. v0.4 uses Beta priors for both truth and survival probabilities.

Default truth prior:

```text
Beta(2, 2)
```

Default survival prior:

```text
Beta(2, 2)
```

One successful observation therefore does not imply a 100% trustworthy route.

## Prediction-bias rule

Prediction error remains:

```text
observed_edge_bps - expected_edge_bps
```

Only negative historical bias may adjust the current edge:

```text
bias_penalty = min(0, mean_prediction_error_bps)
bias_adjusted_edge = max(0, raw_edge + bias_penalty)
```

Positive historical prediction error never increases a current opportunity. Reliability history may calibrate or suppress an edge, but it may not manufacture one.

## Score

For sufficiently evidenced candidates:

```text
adjusted_score_bps
  = bias_adjusted_edge_bps
    * smoothed_truth_rate
    * smoothed_survival_rate
    * history_confidence
```

The score is an advisory paper-ranking value, not realized PnL and not a live-trading instruction.

## Statuses

- `RANKED`: positive `EXECUTE_SIM` candidate with enough matching history.
- `INSUFFICIENT_HISTORY`: candidate remains observable but is not promoted to a trusted reliability-ranked signal.
- `SUPPRESSED_BY_HISTORY`: historical negative bias consumes the positive raw edge.
- `INELIGIBLE`: non-positive raw edge or verifier verdict is not `EXECUTE_SIM`.

Cross-venue `OBSERVE_ONLY_REBALANCE_UNMODELED` candidates remain ineligible until explicit rebalance/settlement edges exist.

## Determinism

Ranking uses stable tie-breaking after status and scores:

```text
status priority
-> adjusted score descending
-> provisional score descending
-> raw edge descending
-> candidate_id ascending
```

This makes the same candidate/history inputs produce the same order.

## Safety boundary

v0.4 remains paper-only. It introduces no private exchange API, account access, signing, order placement, wallet interaction, transfer, bridge or live-execution path.
